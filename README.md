# 천천히 해도 괜찮아요 — 스마트폰 생활 퀴즈

경비노동자를 위한 스마트폰 생활 퀴즈 사이트입니다. 로그인 없이 QR코드나 주소로 바로 접속해,
카카오톡·보안(사기 예방)·용량 정리·승차권·픽토그램·키오스크 6개 주제 중 원하는 것을 골라
짧은 상황형 퀴즈를 풀어볼 수 있습니다. `docs/기획안.docx`의 설계 원칙(한 화면 한 행동, 큰 글씨
큰 버튼, 실수해도 안전, 개인정보 미수집 등)을 따라 만들었습니다.

## 실행 방법

빌드 도구나 서버가 필요 없는 정적 웹앱입니다. `index.html`을 브라우저로 열거나,
아무 정적 파일 서버(예: `npx serve .`)로 서비스하면 됩니다. QR코드로 접속하는 운영 방식에도
그대로 사용할 수 있습니다.

## 주요 기능

- **주제 선택**: 6개 주제 중 하나 이상을 골라 연습하거나, "전체 복습"으로 모두 섞어 풀 수 있습니다.
- **문항/선택지 순서 랜덤화**: 퀴즈를 시작할 때마다(첫 시도, 전체 다시 풀기, 오답만 다시 풀기 모두)
  문항 순서와 각 문항의 선택지 순서를 매번 새로 섞습니다. (`js/app.js`의 `shuffle()` 참고)
- **비경쟁적 피드백**: 오답에도 감점이나 경고 없이 "한 번 더 확인해 볼까요?"와 설명을 보여주고,
  같은 문제를 다시 풀 수 있습니다.
- **결과는 점수가 아닌 상태로 표시**: 주제별로 "혼자 가능" / "다시 보기"로 안내하고, 오답만 다시
  풀기 / 처음부터 다시 풀기(둘 다 순서 랜덤)를 제공합니다.
- **접근성**: 글자 크게 보기, 문제 읽어 주기(Web Speech API) 토글을 시작 화면에 배치했습니다.
- **개인정보 미수집**: 이름, 전화번호, 로그인 등을 전혀 요구하지 않습니다.

## 파일 구조

```
index.html        화면 마크업 (시작 → 주제 선택 → 안내 → 퀴즈 → 결과)
css/style.css      큰 글씨/큰 버튼 기반의 모바일 우선 스타일
js/data.js         문제 데이터 (주제별 문항, 선택지, 정답, 설명) — 내용 수정은 이 파일만 고치면 됩니다
js/app.js          화면 전환, 셔플, 채점, 결과 집계 로직
```

## 문항 추가/수정

`js/data.js`의 `TOPICS` 배열에 항목을 추가하면 됩니다. 각 문항은 다음 형태입니다.

```js
{
  situation: "(선택) 상황 설명 한두 문장",
  prompt: "질문 문장",
  choices: [
    { text: "선택지 1", correct: false },
    { text: "선택지 2", correct: true }
  ],
  explain: "정답 뒤에 보여줄 설명"
}
```

화면 코드를 손대지 않고 문항 수·내용만 늘릴 수 있도록 설계했습니다. 현재 6개 주제, 총 23문항이
들어 있으며, 한 회차에는 6~8문항이 무작위로 제시됩니다(주제를 하나만 고르면 해당 주제의 전체
문항이 나옵니다).

## 기획안과의 차이 / 향후 확장

이번 버전은 기획안의 "참여자 화면(퀴즈 풀기)"에 집중한 MVP입니다. 강사용 진행 화면, QR 세션 생성,
익명 응답 집계, 관리자 문제 편집기 등은 기획안 7장의 "향후 기능"에 해당하며 이번 범위에는
포함하지 않았습니다. 필요해지면 `js/data.js`를 백엔드 API로 교체하는 방식으로 확장할 수 있도록
데이터와 화면 로직을 분리해 두었습니다.
